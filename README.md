# Simple Snake Game

파이썬과 Pygame으로 구현한 뱀 게임입니다.

## 기능

- **세 가지 게임 모드**
  - Classic 모드: 뱀이 자동으로 이동, 방향키로 방향 전환
  - Relaxed 모드: 키 입력시에만 이동, 잘못된 이동은 무시
  - Museum 모드: 알고리즘이 뱀을 자동 조종하여 보드를 채우는 과정을 관람
- **보드 크기 설정**: 6x6 ~ 32x32 셀 사이에서 자유롭게 조정
  - 일반 조정: 1칸씩 증감
  - 빠른 조정: Shift + 방향키로 10칸씩 증감
- **고정 윈도우**: 800x800 픽셀 윈도우에 게임판이 중앙 정렬
- **점수 시스템**: 시작 1점, 먹이 하나당 +1점
- **클리어 통계**: 보드를 채우면 이동 횟수, 소요 시간, 효율을 표시
- **게임 종료 화면**: 재시작 또는 메인 메뉴 선택 가능

## 설치 및 실행

### 필요 사항
- Python 3.10 이상
- uv 패키지 매니저

### 실행 방법

```bash
# 최초 1회 의존성 설치
uv sync

# 게임 실행
uv run python snake_game.py
```

## 게임 조작법

### 시작 화면
- **방향키 (↑ ↓)**: 커서 이동
- **방향키 (← →)**: 보드 크기 조정
  - 일반: 1칸씩 증감
  - Shift + 좌우: 10칸씩 증감
- **ENTER / SPACE**: Classic 또는 Relaxed 모드 시작, Museum 모드는 알고리즘 선택으로 이동

### 알고리즘 선택 화면
- **방향키 (↑ ↓)**: 알고리즘 선택
- **ENTER / SPACE**: 선택한 알고리즘으로 관람 시작
- **ESC**: 시작 화면으로 돌아감

### 게임 중
- **방향키 (↑ ↓ ← →)**: 뱀 이동 또는 방향 전환
- **Q**: 게임 오버

### 게임 오버 / 클리어 화면
- **방향키 (↑ ↓)**: 메뉴 선택
- **ENTER**: 선택 확인
- **R**: 즉시 재시작

## 게임 규칙

### Classic 모드
1. 뱀이 자동으로 이동, 방향키로 방향만 변경
2. 빨간색 먹이를 먹으면 뱀이 즉시 성장하고 점수 +1
3. 벽이나 자기 몸에 부딪히면 게임 오버
4. 뱀은 마지막 실제 이동 방향의 반대로 회전할 수 없음
5. 보드를 완전히 채우면 게임 클리어

### Relaxed 모드
1. 키를 누를 때만 한 칸씩 이동
2. 빨간색 먹이를 먹으면 뱀이 즉시 성장하고 점수 +1
3. 벽이나 자기 몸으로 가는 입력은 무시됨
4. 보드를 완전히 채우면 게임 클리어

### Museum 모드
1. 알고리즘이 뱀을 자동으로 조종하여 보드를 빈틈없이 채운다
2. 사용자는 관람만 하며, 방향 입력은 무시됨
3. 알고리즘마다 보드 크기 제약 조건이 다를 수 있음

### 관람 가능한 알고리즘

- **Comb**: 왼쪽 열을 올라간 뒤 나머지를 지그재그로 훑는 해밀턴 순환 경로. height가 짝수일 때만 동작

### 클리어 통계

보드를 꽉 채우면 다음 정보가 표시된다.
- **Moves**: 총 이동 횟수
- **Time**: 소요 시간 (초)
- **Efficiency**: (보드 칸수 - 1) / 이동 횟수 x 100. 경로 낭비 없이 최단으로 채울수록 100%에 가까움
